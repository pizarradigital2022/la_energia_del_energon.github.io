Logaritmos

Definición de logaritmo

El logaritmo es la operación inversa de la potenciación.
Si tenemos una potencia:

\(b^x = y\)

donde:

  • \(b\) es la base (un número positivo distinto de 1),
    • cuando la base es el número \(e=2,71828...\) se dice logaritmo neperiano.
    • cuando la base es \(10\) se dice logaritmo decimal.
  • \(x\) es el exponente,
  • \(y\) es el resultado,

entonces el logaritmo de \(y\) en base \(b\) es el exponente \(x\) que necesitamos para obtener \(y\) al elevar \(b\) a esa potencia:

\(\log_b(y) = x \quad \Longleftrightarrow \quad b^x = y\)

Ejemplo:

\(2^3 = 8 \quad \Rightarrow \quad \log_2(8) = 3\)


Propiedades de los logaritmos

Los logaritmos tienen varias propiedades importantes que nos permiten simplificar cálculos y resolver ecuaciones.

2.1 Logaritmo del producto

\(\log_b(M \cdot N) = \log_b(M) + \log_b(N)\)

Ejemplo:

  • \(\log_2(8 \cdot 4) = \log_2(32) = 5\)
  • \(\log_2(8) + \log_2(4) = 3 + 2 = 5\)

2.2 Logaritmo del cociente

\(\log_b\left(\frac{M}{N}\right) = \log_b(M) - \log_b(N)\)

Ejemplo:

  • \(\log_3\left(\frac{27}{3}\right) = \log_3(9) = 2\)
  • \(\log_3\left(\frac{27}{3}\right) = \log_3(27) - \log_3(3) = 3 -1 = 2\)

2.3 Logaritmo de una potencia

\(\log_b(M^p) = p \cdot \log_b(M)\)

Ejemplo:

  • \(\log_5(25^2) = \log_5(625) = 4\)
  • \(\log_5(25^2) =2 \cdot \log_5(25) = 2 \cdot 2 = 4\)

2.4 Logaritmo de la base

\(\log_b(b) = 1\)

2.5 Logaritmo de 1

\(\log_b(1) = 0\)

2.6 Logaritmo de una raíz cuadrada

\(\log_b(\sqrt{x}) = \log_b(x^{1/2}) = \tfrac{1}{2}\log_b(x)\)

Para el caso de una raíz enésima sería:

\(\log_b(\sqrt[n]{x}) = \log_b(x^{1/n}) = \tfrac{1}{n}\log_b(x)\)

Ejemplo:

  • \(log_2(\sqrt{16}) = \tfrac{1}{2}\log_2(16) = \tfrac{1}{2} \cdot 4 = 2\)
  • \(log_2(\sqrt{16}) = \log_2(4) =  2\)

2.7. Logaritmo de una fracción unitaria

\(\log_b\left(\frac{1}{x}\right) = \log_b(x^{-1}) = - \log_b(x)\)

Ejemplo:

  • \(\log_{10}\left(\frac{1}{100}\right) = \log_{10}(100^{-1}) = - \log_{10}(100) = - 2\)

2.8. Cambio de base

Sirve para calcular logaritmos en cualquier base:

\(\log_b(x) = \frac{\log_k(x)}{\log_k(b)}\)

(\(k\) puede ser \(10\) o \(e\) normalmente)

Ejemplo:

  • \(\log_2(8) = \frac{\log_{10}(8)}{\log_{10}(2)} \approx \frac{0.903}{0.301} = 3\)

Ecuaciones logarítmicas

Una ecuación logarítmica es aquella en la que aparece un logaritmo de incógnita \(x\).

Método general

  • Usar las propiedades de los logaritmos para simplificar la ecuación.
  • Transformar la ecuación logarítmica en una ecuación exponencial si es necesario.
  • Resolver la ecuación y verificar que el resultado es válido (el logaritmo solo está definido para números positivos).

Ejemplos

Ejemplo 1:

\(\log_2(x) = 3\)

Convertimos a forma exponencial:

\(2^3 = x \quad \Rightarrow \quad x = 8\)

Ejemplo 2:

\(\log_3(x) + \log_3(9) = 4\)

Aplicamos la propiedad del producto:

\(\log_3(9x) = 4\)

Convertimos a exponencial:

\(3^4 = 9x \quad \Rightarrow \quad 81 = 9x \quad \Rightarrow \quad x = 9\)

Ejemplo 3:

\(\log_5(x^2) = 6\)

Usamos la propiedad de la potencia:

\(2 \cdot \log_5(x) = 6 \quad \Rightarrow \quad \log_5(x) = 3\)

Convertimos a exponencial:

\(5^3 = x \quad \Rightarrow \quad x = 125\)

Ejemplo 4: Ecuación con logaritmo del otro lado del igual:
\(5^{x} = 125\)

Primero escribimos como logaritmo (pasamos el exponente a logaritmo):

\(x=log⁡5(125)\)

Luego resolvemos:

\(5^3 = 125 \quad \Rightarrow \quad x = 3\) ✅

Aquí el logaritmo estaba del otro lado del igual, ya que la ecuación original era exponencial.

 
Ejemplo 5: Ecuación con logaritmo en la base distinta del 10
\(\log_2(x) = 4\)

Usamos la definición de logaritmo:

\(2^4 = x \quad \Rightarrow \quad x = 16\)

Si quieres complicarlo un poco más, también podemos combinar con otras propiedades:

\(\log_3(x-2) = 2 \Rightarrow 3^2 = x - 2 \quad \Rightarrow \quad 9 = x - 2 \quad \Rightarrow \quad x = 11\)

Ejemplo 6: hallar la base de un logaritmo
\(\log_b(16) = 4\)

Aquí la incógnita es \(b\) (la base). Aplicamos la definición de logaritmo:

\(b^4 = 16\)

Ahora resolvemos para \(b\):

\(b = \sqrt[4]{16} = 2\)✅

Resultado: \(b=2\)

Ejemplo 7: Otro ejemplo con paso intermedio
\(\log_b(81) = 4\)

Definimos en forma exponencial:

\(b^4 = 81\)

Como \(81 = 3^4\), tenemos:

\(b^4 = 3^4 \quad \Rightarrow \quad b = 3\)
